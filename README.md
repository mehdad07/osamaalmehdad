# Personal Hub — موقع شخصي عربي

موقع شخصي من صفحة واحدة مبني بـ Vanilla TypeScript وHTML وCSS، مع خادم Node.js وExpress مكتوب بـTypeScript. لا توجد قاعدة بيانات ولا أطر واجهة مثل React. يحتوي الموقع على خمس صفحات داخلية تعمل دون إعادة تحميل: من أنا، السيرة الذاتية، التعليم، الرؤية، وتواصل معي.

## شجرة الملفات

```text
personalhub/
├── public/
│   ├── index.html          # الهيكل الدلالي والمحتوى الأولي
│   ├── styles.css          # التصميم والاستجابة والوضعان الفاتح والداكن
│   ├── manus-routes.json   # تعريف المسار العام الوحيد /
│   └── images/
│       └── profile-placeholder.svg # صورة افتراضية قابلة للاستبدال
├── src/
│   ├── server.ts           # خادم Express وتقديم الملفات الثابتة
│   └── client/
│       ├── data.ts         # كل بيانات الملف الشخصي القابلة للتعديل
│       └── main.ts         # منطق التبويبات والثيم ورسم المحتوى
├── scripts/
│   ├── clean.mjs           # حذف dist قبل البناء
│   └── copy-public.mjs     # نسخ public إلى dist/public
├── app.config.ts           # هوية مشروع Webdev
├── package.json            # الاعتماديات وأوامر npm
├── package-lock.json       # قفل نسخ الاعتماديات بعد npm install
├── tsconfig.json           # إعداد TypeScript الصارم
├── .gitignore
├── plan.md
├── TODO.md
└── README.md
```

## التشغيل المحلي

تحتاج إلى Node.js حديث (يفضل Node 20 أو أحدث). من جذر المشروع شغّل:

```bash
npm install
npm run build
npm start
```

ثم افتح `http://localhost:3000`.

أثناء التطوير، استخدم خادم المراقبة وإعادة التشغيل التلقائي:

```bash
npm run dev
```

يعمل الخادم التطويري على `http://localhost:3000` ويقدّم الملفات من `public/`. بعد `npm run build`، يترجم TypeScript إلى `dist/` وينسخ ملفات العرض إلى `dist/public/`، ثم يقدّم `npm start` النسخة المترجمة.

## أوامر التحقق

```bash
npm run typecheck   # فحص TypeScript دون إنشاء ملفات
npm run build       # تنظيف dist ثم الترجمة والنسخ
```

يوجد أيضاً المسار `GET /health` للتحقق من جاهزية الخادم، و`GET /manus-routes.json` لتعريف الصفحة العامة الوحيدة. يقوم البناء الآن بنسخ JavaScript إلى `dist/public/client` ويقدّمه الخادم عبر `/client` حتى تعمل التبويبات والوضع الداكن بعد `npm start`.

## استبدال الصورة الشخصية

الصورة الحالية مؤقتة وموجودة في `public/images/profile-placeholder.svg`. لاستبدالها بصورة حقيقية:

1. ضع صورتك داخل مجلد `public/images`، مثلاً باسم `profile.jpg`.
2. افتح `src/client/data.ts` وغيّر قيمة `profile.image` إلى:

```ts
image: '/images/profile.jpg',
```

3. إذا كانت الصورة PNG فاستخدم `profile.png` بدلاً من `profile.jpg`.
4. شغّل `npm.cmd run build` ثم `npm.cmd start` على Windows، أو `npm run build` ثم `npm start` على الأنظمة الأخرى.

تظهر الصورة تلقائياً في القسم العلوي من الصفحة وفي تبويب «من أنا».

## تعديل المحتوى

عدّل الملف `src/client/data.ts` لتغيير الاسم، المسمى الوظيفي، النبذة، روابط التواصل، الخبرات، المهارات، الشهادات، الرؤية وبيانات التواصل. لا تحتاج إلى تعديل منطق الصفحات. بعد التعديل شغّل `npm run build` ثم `npm start`، أو استخدم `npm run dev` أثناء التطوير.

## ملاحظات التصميم

التبويبات الخمسة موجودة داخل الصفحة الرئيسية وتعمل كصفحات داخلية عبر hash مثل `#about` و`#contact` دون إعادة تحميل، مع معالجة نقر مباشرة على حاوية التبويبات حتى تستجيب عند الضغط على النص أو الرقم داخل الزر. على الجوال تصبح التبويبات شريطاً أفقياً قابلاً للتمرير، وتعمل لوحة المفاتيح بأسهم الاتجاه للتنقل بينها. الوضع الفاتح والداكن محفوظان في `localStorage` مع التعامل الآمن مع المتصفحات التي تمنع التخزين، ويحترم الموقع تفضيل نظام التشغيل عند أول زيارة.

أضيفت هوية بصرية رسمية ومبتكرة بخلفية بيضاء افتراضية ولوحة كحلية/فيروزية مؤسسية، بطاقات وحدود واضحة، شبكة رقمية هادئة، مدار حول العلامة، ووسم `HUMAN × AI × FUTURE`. كما تم استبدال ملف CSS الناقص بملف كامل يحتوي على التخطيط والألوان والبطاقات والتجاوب والوضعين الفاتح والداكن. تحترم الحركة إعداد `prefers-reduced-motion` لإيقاف المؤثرات لمن يحتاجها.
